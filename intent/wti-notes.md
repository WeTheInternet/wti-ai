# WTI Notes (Provisional)

## Purpose

These notes capture how WTI may help as a provisional human-facing format while the richer internal model is still evolving.

The exact final product does not need to use WTI as its source of truth.

## Current understanding

Based on the supplied grammar, WTI clearly supports a structured document style with:
- sections
- rows
- bullets
- nested blocks
- link/reference-like constructs
- quoted content
- inline and block-oriented composition

That is already enough to use it as a discussion and acceptance-criteria language for many structured human-facing documents.

## Why WTI is attractive here

The project wants a representation that can feel natural to humans while still preserving branching structure.

WTI looks promising for:
- structured summaries
- acceptance criteria drafts
- deliberation exports
- quoted dialogue-like snippets
- nested branch summaries
- UI-oriented document rendering

## Important limitation

The internal deliberation and knowledge model almost certainly needs to be richer than current WTI surface syntax.

For example, the internal model likely wants to distinguish:
- matter
- proposal
- reason
- judgment
- decision
- authority
- status
- supersession
- archived lineage
- dependency links

WTI can still be useful as:
- an exchange format
- a rendering format
- a human-readable summary format
- a provisional authoring syntax

## Recommended stance

Treat WTI as:
- useful now
- good for examples and acceptance criteria
- not yet the final underlying data model

That keeps the project flexible.

## One good use immediately

WTI is a reasonable way for the project to discuss and prototype structured deliberation outputs before freezing a richer storage model.
