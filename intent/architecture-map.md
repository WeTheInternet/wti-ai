# Architecture Map

## Short pipeline

`idea -> candidate intent -> accepted intent -> (deliberation | research | spec | work plan | direct work) -> validation -> promotion`

## Active roles

- Orchestrator — clarifies, routes, and governs transitions
- Guru — compiles just-in-time context
- Worker — performs bounded work
- Validator/Critic — checks, challenges, and protects quality
- Chronicler — records chronology and assists explicit commits

## Core stores

- active authoritative knowledge
- non-authoritative chronological logs
- graveyard/archive

## Core activity panes

- orchestrator
- deliberation
- spec builder
- work plan
- verification
- artifact/document views
