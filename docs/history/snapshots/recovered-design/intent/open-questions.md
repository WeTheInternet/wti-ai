# Open Questions Intentionally Preserved

## Purpose

These questions are still genuinely open and should remain visible rather than being prematurely decided.

## Deliberation lifecycle

- What exact lifecycle states should branches have?
- How formal should branch closure be?
- When does a child reply become its own matter?

## Naming

- Should the broader checking role be called Validator, Critic, Reviewer, or something else?
- Should Task-Agent be fully replaced by Worker everywhere?

## Weighting

- What is the right minimal internal model behind the simple thumbs-down / comment / thumbs-up UI?
- How much explicit confidence metadata is worth carrying early?

## Fact classification

- How many categories should be first-class early: fact, assumption, belief, observation, decision, precedent?
- Which of these need distinct system behavior versus just tags?

## Rehydration

- How smart should the eventual "conversation reviver" be?
- Should it propose which roles to re-engage automatically, or only summarize and ask?

## UI metaphor

- For deliberation, what should be primary: thread, graph, case file, or some hybrid?
- What is the smallest useful user action in each pane?

## Retrieval

- How much invalidation should be periodic versus reactive?
- When is deeper temporal modeling worth the complexity?

## WTI

- Which structured outputs are best expressed in WTI right away?
- Which concepts clearly exceed WTI's current surface syntax?

## Consensus models

- Which domain-specific approval models should be formalized first after the single-human software-first model?
